Generating LED Patterns Using Arduino

This project demonstrates different lighting patterns using multiple LEDs controlled by an Arduino microcontroller. The LEDs are arranged on a dotted PCB board and programmed to glow in various sequences to create visual patterns and effects.

By controlling the timing and order in which each LED turns ON and OFF, different animations such as running lights, blinking groups, wave patterns and alternate flashing are produced.

Working Principle

  • Each LED is connected to a digital output pin of the Arduino
  • Arduino sends HIGH and LOW signals to control each LED
  • Delays are used to create visible movement effects
  • Different loop sequences generate different light patterns

Main Components Used

  • Arduino Uno
  • Multiple LEDs
  • 220Ω current limiting resistors
  • Dotted PCB (general purpose board)
  • Connecting wires
  • USB power supply

Lighting Patterns Implemented

  • Left to right running light
  • Right to left running light
  • Alternate LED blinking
  • All LEDs ON and OFF blinking
  • Wave / chase effect

Features

  • Simple and low-cost design
  • Easy to modify and expand
  • Useful for learning digital output control
  • Can be adapted for decorative lighting

Applications

  • LED decoration and display boards
  • Basic robotics and signalling
  • Learning Arduino programming
  • Light show and pattern experiments

Future Improvements

  • Add push buttons to change patterns
  • Use PWM for brightness control
  • Create music-synchronised patterns
  • Design a custom PCB for compact size
