AgriGuard – Smart IoT System for Farming & Security

AgriGuard is an IoT-based smart agriculture and security system built using an ESP32 microcontroller. It helps farmers automate irrigation, monitor environmental conditions, and protect crops using connected sensors and internet-based monitoring.

The system continuously reads soil moisture, temperature and humidity data, and sends this information to the cloud using Wi-Fi. Based on soil moisture level, it can automatically turn on a water pump for irrigation. It also includes fire and intrusion detection to improve farm security.

Working Principle

  • Soil moisture sensor measures water level in the soil
  • DHT sensor reads temperature and humidity
  • ESP32 processes sensor data in real time
  • Data is uploaded to the ThingSpeak cloud platform via Wi-Fi
  • If soil is dry, the relay turns ON the irrigation motor automatically
  • If fire or intrusion is detected, buzzer/alert is activated

Main Components Used

  • ESP32 Wi-Fi microcontroller
  • Soil moisture sensor
  • DHT11 temperature & humidity sensor
  • Relay module for motor control
  • Water pump
  • Fire sensor / flame sensor
  • Buzzer for alert
  • Power supply and connecting wires

Features

  • Automatic irrigation based on soil condition
  • Real-time monitoring through internet
  • Cloud data logging using ThingSpeak
  • Low water wastage and efficient farming
  • Fire and security alert system
  • Remote access from mobile or laptop

Applications

  • Smart agriculture and precision farming
  • Greenhouse monitoring
  • Garden and lawn automation
  • Farm security and safety systems

Future Improvements
