AgriGuard – Smart IoT Farming & Security System

AgriGuard is an all-in-one smart agriculture system designed to automate irrigation and provide field security using sensors and an Arduino-based controller. It continuously monitors soil moisture, fire risk, and human intrusion to protect crops and reduce manual work.

The system automatically waters plants only when the soil becomes dry, detects fire or high temperature conditions, and triggers alerts when unauthorized movement is sensed near the protected area. All data is displayed locally on an OLED screen and can also be sent online for remote monitoring.

Working Principle

  • Soil moisture sensor checks the water content in soil
  • If soil is dry, Arduino turns ON the water pump automatically
  • Flame/temperature sensor detects fire or abnormal heat
  • PIR sensor detects human or animal movement (intrusion)
  • OLED display shows live status of all sensors
  • IoT module sends data to the internet for remote viewing

Main Components Used

  • Arduino (Uno/Nano)
  • Soil moisture sensor
  • Flame or temperature sensor
  • PIR motion sensor
  • Relay module and water pump
  • OLED display
  • ESP8266 / WiFi IoT module
  • Power supply and connecting wires

Functions Implemented

  • Automatic irrigation control
  • Fire detection and warning
  • Intrusion/security detection
  • Real-time sensor monitoring on OLED
  • Online IoT based remote monitoring

Features

  • Saves water by watering only when needed
  • Improves crop safety with fire and intrusion alerts
  • Reduces manual monitoring effort
  • Low-cost and suitable for small farms and gardens

Applications

  • Smart irrigation for agriculture fields
  • Home gardens and greenhouses
  • Farm security and boundary monitoring
  • IoT based remote farming systems

Future Improvements
