Smart IoT System for Farming & Security project is basically an all-in-one smart agriculture system that combines: Automatic irrigation Fire detection Intrusion/security detection Real-time monitoring (both locally on OLED and online through IoT) Let’s go step by step in full detail. 1. Purpose of the Project In normal farming or gardening: People manually water plants → wastes water and time There is no immediate warning for fire accidents Fields/gardens are not protected from unauthorized entry Your project solves all three problems by using sensors and automation: Water only when soil is dry Alert immediately if fire is detected Alert if someone crosses the protected boundary All data is continuously shown on an OLED screen and also sent to the internet for remote monitoring. Main Components and Their Roles ESP32 Microcontroller Brain of the system Reads all sensors Controls pump, buzzer, display Sends data to the cloud through Wi-Fi Soil Moisture Sensor Measures how wet or dry the soil is If soil is dry → ESP32 turns ON water pump Relay Module + Water Pump Relay acts like an electronic switch ESP32 gives small signal → relay turns ON pump safely Pump waters the plants automatically Flame Sensor Detects fire or high heat If fire is sensed → buzzer sounds immediately Laser + LDR (Light Dependent Resistor) Laser beam is continuously falling on LDR If someone crosses and breaks the beam → intrusion detected Buzzer alert is triggered DHT11 Sensor Measures temperature and humidity of air OLED Display Shows live values: Temperature Humidity Soil moisture Fire status Security status Buzzer Gives sound alert for: Fire Unauthorized entry Power Supply Provides stable voltage to all components (All these blocks are integrated into one single smart system.) Working Methodology All sensors are connected to ESP32 ESP32 continuously reads: Soil moisture Temperature & humidity Flame sensor Laser–LDR security status Values are compared with preset limits: If soil is dry → Pump ON If fire detected → Buzzer ON If laser beam breaks → Buzzer ON Current readings are shown on OLED in real time ESP32 connects to Wi-Fi and uploads data to cloud (ThingSpeak) User can monitor everything remotely from anywhere This whole process runs automatically without manual control. � AGRIGUARD final ppt-2.pptx None 5.
