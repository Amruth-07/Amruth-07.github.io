Portable Oscilloscope using Arduino and OLED

This project is a small, low-cost portable oscilloscope that can visualize electrical signals as waveforms in real time. Instead of using a bulky laboratory oscilloscope, it uses an Arduino microcontroller and a tiny OLED display to observe signal shapes.

The input analog voltage is sampled by the Arduino, converted into digital values, and then plotted as a moving waveform on the OLED screen. This makes it possible to “see” signals like sine waves, square waves, and triangle waves during experiments and testing.

Working Principle

  • Analog signal is applied to the Arduino ADC input pin
  • Arduino samples the signal at high speed
  • Sampled values are scaled to fit the OLED screen height
  • Points are drawn continuously to form a live waveform
  • Buffer updates create scrolling real-time display

Main Components Used

  • Arduino Nano / Uno
  • 0.96" OLED display (SSD1306)
  • Resistor voltage divider for input protection
  • Push buttons for control (optional)
  • Battery or USB power supply
  • Connecting wires and small PCB

Functions Implemented

  • Real-time waveform visualization
  • Adjustable time/division (sampling speed)
  • Adjustable voltage scaling
  • Basic triggering for stable display
  • FFT mode for simple frequency analysis (optional)

Features

  • Compact and fully portable design
  • Very low cost compared to lab oscilloscopes
  • Good for learning and basic signal testing
  • Can display sine, square, triangle and noisy signals

Applications

  • Electronics lab experiments
  • Debugging Arduino sensor signals
  • Learning about waveforms and frequency
  • Quick field testing of low-voltage signals

Future Improvements

  • Add rotary encoder for smooth control
  • Increase sampling rate using optimized ADC
  • Add signal storage and freeze function
  • Design custom PCB enclosure for handheld use
