Portable Oscilloscope using Arduino ## Working Principle - The analog signal is applied to the Arduino ADC pin - Arduino samples the signal using its built-in ADC - Sampled values are mapped to pixel coordinates - The waveform is drawn on the OLED display ## Features - Displays sine, square, and triangle waveforms - Portable and low power - Real-time signal visualization - Low-cost alternative to lab oscilloscopes ## Applications - Educational labs - Signal testing - Embedded system debugging
