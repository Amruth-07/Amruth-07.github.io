All-in-One Electronic Component Tester

This project is a compact and low-cost electronic component tester built using an Arduino microcontroller. It is designed to quickly identify and measure common electronic components such as resistors, capacitors, diodes, transistors and also perform continuity checking.

The tester automatically detects the type of component connected to the test terminals and displays the result on a small OLED display. This removes the need for multiple separate measuring instruments and makes circuit testing faster and easier.

Working Principle

  • The unknown component is connected to the test pins
  • Arduino applies different test voltages and currents
  • Voltage and current responses are measured using ADC
  • Based on the electrical behaviour, the component type is identified
  • Measured values are calculated and shown on the OLED display

Functions Supported

  • Resistance measurement (Ohms)
  • Capacitance measurement (pF to µF range)
  • Diode testing and forward voltage drop display
  • NPN and PNP transistor identification and pinout
  • Continuity checking with buzzer indication

Main Components Used

  • Arduino Nano / Arduino Uno
  • 0.96" OLED display (I2C)
  • Precision resistors for measurement network
  • Push buttons for test control
  • Buzzer for continuity alert
  • Test sockets / probes

Features

  • Automatic component recognition
  • Fast and accurate measurements
  • Portable and battery powered
  • Simple user interface with single button operation
  • Useful for troubleshooting and lab work

Applications

  • Electronics lab experiments
  • Repair and maintenance of circuits
  • Component sorting and identification
  • Educational learning tool for students

Future Improvements

  • Inductor and ESR measurement
  • Graphical waveform display
